دستیار هوش مصنوعی موزونی

این یه چت‌بات واقعیه، نه یه نمونه‌ی ساختگی. مستقیم از همین مرورگر، با Claude (مدل هوش مصنوعی شرکت Anthropic) صحبت می‌کنی. تو مقاله‌ی قبلی با چند تا ابزار هوش مصنوعی معروف آشنا شدی؛ این صفحه یکی از همون‌ها رو مستقیم تو سایت در اختیارت می‌ذاره.

برای استفاده، کلید API شخصی‌ت رو وارد کن

چون این سایت یه سایت استاتیکه (روی GitHub Pages) و سرور جداگانه‌ای نداره، نمی‌تونه یه کلید مشترک برای همه نگه داره. به‌جاش، هر کاربر با کلید API شخصی خودش مستقیم به Claude وصل می‌شه. کلید فقط تو همین مرورگر خودت (localStorage) ذخیره می‌شه و به هیچ سروری جز Anthropic فرستاده نمی‌شه.

کلید نداری؟ از کنسول Anthropic یه حساب بساز و یه کلید API بگیر (هزینه‌ش بر اساس تعرفه‌ی فعلی Anthropic و میزان استفاده‌ته).

هنوز کلیدی ذخیره نشده.

گفتگو خالیه — یه پیام بنویس و شروع کن.

قبل از استفاده بدون

  • کلید API مثل یه رمز عبوره. هیچ‌وقت اون رو تو کد یه سایت عمومی ننویس یا با کسی به اشتراک نذار؛ همین‌جا هم فقط تو مرورگر خودت ذخیره می‌شه، جای دیگه‌ای فرستاده نمی‌شه.
  • استفاده از Claude API رایگان نیست؛ طبق تعرفه‌ی Anthropic و تعداد توکن مصرفی هزینه داره. برای شروع، یه سقف هزینه‌ی کم تو حساب Anthropic‌ت تنظیم کن.
  • چون کلید تو مرورگر ذخیره می‌شه، روی کامپیوتر مشترک یا عمومی ازش استفاده نکن، و بعد از کار، دکمه‌ی «حذف کلید» رو بزن.
  • گفتگو فقط تو همین صفحه و همین مرورگر نگه داشته می‌شه؛ با بستن یا رفرش صفحه، گفتگوی قبلی از بین می‌ره.
