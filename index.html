Markdown چیست؟

اگه تا حالا تو گیت‌هاب یه فایل README.md دیدی یا تو یه فروم متنی رو با ستاره‌ها بولد کردی، با Markdown آشنا شدی. Markdown یه زبان نشانه‌گذاری سبکه که به‌جای تگ‌های پیچیده‌ی HTML، با چند تا کاراکتر ساده مثل # و * متن رو قالب‌بندی می‌کنی. تو این مقاله یاد می‌گیری Markdown چیه، چرا به وجود اومد، چطور تیتر و لیست و جدول بنویسی، و چه فرقی با HTML داره.

GitHub چیست؟

GitHub جاییه که پروژه‌های کدنویسی ذخیره، نسخه‌بندی و به اشتراک گذاشته می‌شن. تو این مقاله یاد می‌گیری فرق Git و GitHub چیه، ریپازیتوری، کامیت و برنچ یعنی چی، و چطور یه اکانت بسازی و شروع کنی. این مقاله بخش اوله از یه سه‌گانه: بخش دوم دستورهای عملی Git رو یاد می‌ده و بخش سوم نحوه‌ی انتشار سایت با GitHub Pages، امنیت اکانت و آشنایی با GitHub Actions رو پوشش می‌ده.

HTML چیست؟

هر صفحه‌ای که تو مرورگر باز می‌کنی، پایه و اسکلتش HTML‌ه. HTML به‌جای طراحی ظاهر، ساختار محتوای صفحه رو مشخص می‌کنه: کجا تیتره، کجا پاراگرافه، کجا لینکه. تو این مقاله یاد می‌گیری ساختار یه سند HTML چیه، تگ و ویژگی (attribute) یعنی چی، و چرا تگ‌های سمانتیک مثل header و article به‌جای div ساده اهمیت دارن.

CSS چیست؟

رنگ، فونت و چیدمان هر سایتی کار CSS‌ه. CSS به مرورگر می‌گه هر عنصر HTML چه شکلی نشون داده بشه و کجای صفحه قرار بگیره. تو این مقاله یاد می‌گیری سینتکس پایه‌ی CSS چیه، سه روش اتصالش به HTML (داخلی، درون‌خطی و فایل جدا)، و باکس مدل (Box Model) که پایه‌ی همه‌ی چیدمان‌های وبه.
