آموزش انتشار سایت با GitHub Pages و اتصال دامنه شخصی

اگر یک سایت HTML و CSS روی کامپیوتر خود ساخته‌اید و می‌خواهید آن را به‌صورت رایگان روی اینترنت منتشر کنید، GitHub Pages یکی از ساده‌ترین روش‌ها برای این کار است.

در این آموزش، از ساخت پروژه و آپلود فایل‌ها در GitHub شروع می‌کنیم و سپس GitHub Pages را فعال کرده و در نهایت دامنه شخصی خودمان را به سایت متصل می‌کنیم.

۱. ساخت پروژه سایت روی کامپیوتر

ابتدا یک پوشه برای پروژه سایت خود در کامپیوتر ایجاد کنید. سپس فایل‌ها و پوشه‌های اصلی سایت را داخل آن قرار دهید.

ساختار پیشنهادی پروژه

my-website/
│
├── index.html
├── style.css
│
├── images/
│
└── favicon.ico
  • index.html — فایل اصلی سایت
  • style.css — فایل مربوط به طراحی و ظاهر سایت
  • images/ — پوشه تصاویر سایت
  • favicon.ico — آیکون سایت؛ اختیاری است
💡 نکته: بهتر است نام فایل اصلی سایت دقیقاً index.html باشد؛ زیرا GitHub Pages معمولاً این فایل را به‌عنوان صفحه اصلی سایت شناسایی می‌کند.

۲. ساخت حساب GitHub

برای استفاده از GitHub Pages ابتدا به یک حساب GitHub نیاز دارید. اگر حساب ندارید، یک حساب جدید ایجاد کنید.

نام کاربری GitHub شما در آدرس پیش‌فرض سایت استفاده خواهد شد.

مثال: 
https://USERNAME.github.io/

۳. ساخت Repository برای سایت

پس از ورود به GitHub، یک Repository جدید برای پروژه سایت ایجاد کنید.

  1. روی New Repository کلیک کنید.
  2. برای Repository یک نام انتخاب کنید.
    مثال: mozouni
  3. حالت Repository را روی Public قرار دهید.
  4. روی Create Repository کلیک کنید.
💡 نکته: نام Repository بعداً می‌تواند در آدرس سایت شما دیده شود.

۴. آپلود فایل‌های سایت

پس از ساخت Repository، فایل‌های پروژه خود را در آن آپلود کنید.

  1. وارد Repository شوید.
  2. روی Add file → Upload files کلیک کنید.
  3. فایل‌ها و پوشه‌های پروژه را انتخاب و آپلود کنید.
  4. در انتهای صفحه روی Commit changes کلیک کنید.
⚠️ توجه: مطمئن شوید فایل index.html در مسیر اصلی Repository قرار داشته باشد.

۵. فعال‌سازی GitHub Pages

اکنون می‌توانیم سایت را با استفاده از GitHub Pages منتشر کنیم.

  1. وارد بخش Settings Repository شوید.
  2. از منوی سمت چپ وارد Pages شوید.
  3. در قسمت Build and deployment گزینه زیر را انتخاب کنید:

Source: Deploy from a branch

Branch: main

Folder: /(root)

سپس تنظیمات را ذخیره کنید.

پس از مدتی GitHub Pages سایت شما را منتشر می‌کند.

آدرس پیش‌فرض سایت

https://USERNAME.github.io/REPO-NAME/

برای مثال اگر نام کاربری شما USERNAME و نام Repository شما mozouni باشد: 

https://USERNAME.github.io/mozouni/

۶. ساخت فایل CNAME برای دامنه شخصی

اگر می‌خواهید به‌جای آدرس GitHub از دامنه شخصی خودتان استفاده کنید، می‌توانید دامنه‌ای مانند mozouni.ir را به سایت متصل کنید.

برای این کار یک فایل با نام زیر در Repository ایجاد کنید: 

CNAME

محتوای فایل باید نام دامنه شما باشد: 

mozouni.ir

سپس تغییرات را Commit کنید.

💡 نکته: فایل CNAME باید بدون پسوند ساخته شود؛ یعنی نام فایل دقیقاً CNAME باشد، نه CNAME.txt.

۷. اتصال دامنه به Cloudflare

برای مدیریت DNS دامنه می‌توانیم از Cloudflare استفاده کنیم. ابتدا وارد حساب Cloudflare شوید.

  1. از منوی Cloudflare روی Add a domain کلیک کنید.
  2. دامنه خود را وارد کنید: 
mozouni.ir

سپس روی Continue کلیک کنید.

Cloudflare رکوردهای DNS فعلی دامنه را بررسی می‌کند.

انتخاب پلن

Cloudflare چند پلن مختلف نمایش می‌دهد. برای یک سایت شخصی که با GitHub Pages میزبانی می‌شود، پلن رایگان معمولاً کافی است.

بنابراین می‌توانید گزینه Free را انتخاب کنید.

۸. تنظیم Name Server دامنه

پس از اضافه کردن دامنه به Cloudflare، Cloudflare دو Name Server به شما اختصاص می‌دهد.

برای مثال:

dax.ns.cloudflare.com
gemma.ns.cloudflare.com

این Name Serverها مخصوص دامنه شما هستند و باید دقیقاً همان مقادیری را که Cloudflare نمایش می‌دهد استفاده کنید.

تنظیم Name Server در پنل دامنه

وارد پنل مدیریت دامنه خود شوید و بخش Nameservers را پیدا کنید.

  1. Name Serverهای قبلی را بررسی کنید.
  2. دو Name Server ارائه‌شده توسط Cloudflare را وارد کنید.
  3. تنظیمات را ذخیره کنید.
⚠️ توجه:

تغییر Name Server ممکن است فوراً اعمال نشود. انتشار تغییرات DNS می‌تواند از چند دقیقه تا چند ساعت زمان ببرد.

پس از اینکه Cloudflare Name Serverهای جدید را شناسایی کرد، وضعیت دامنه در Cloudflare فعال می‌شود.

۹. تنظیم رکوردهای DNS

پس از فعال شدن دامنه در Cloudflare، وارد بخش زیر شوید: 

DNS → Records

در داشبورد Cloudflare:

  1. دامنه خود را انتخاب کنید.
  2. وارد بخش DNS شوید.
  3. بخش Records را باز کنید.

۱۰. ساخت رکوردهای A برای GitHub Pages

برای اتصال دامنه اصلی به GitHub Pages، چهار رکورد A ایجاد کنید.

رکورد اول

گزینه مقدار
Type A
Name @
Content 185.199.108.153
Proxy status DNS only

سه رکورد A دیگر

همین تنظیمات را برای IPهای زیر نیز ایجاد کنید:

  • 185.199.109.153
  • 185.199.110.153
  • 185.199.111.153
💡 نکته:

در Cloudflare برای دامنه اصلی معمولاً می‌توانید در قسمت Name از علامت @ استفاده کنید که نشان‌دهنده خود دامنه است.

۱۱. ساخت رکورد CNAME برای www

برای اینکه آدرس www.mozouni.ir نیز به سایت متصل شود، یک رکورد CNAME ایجاد کنید.

گزینه مقدار
Type CNAME
Name www
Target USERNAME.github.io
Proxy status DNS only

به‌جای USERNAME نام کاربری واقعی GitHub خود را وارد کنید.

۱۲. فعال‌سازی دامنه در GitHub Pages

اکنون باید دامنه شخصی خود را در GitHub Pages نیز ثبت کنید.

  1. وارد Repository شوید.
  2. به Settings → Pages بروید.
  3. در قسمت Custom domain دامنه خود را وارد کنید: 
mozouni.ir

سپس روی Save کلیک کنید.

فعال کردن HTTPS

پس از اینکه GitHub گواهی SSL را برای دامنه صادر کرد، گزینه Enforce HTTPS را فعال کنید.

⚠️ توجه:

فعال شدن HTTPS ممکن است کمی زمان ببرد. اگر این گزینه بلافاصله قابل فعال‌سازی نبود، مدتی صبر کنید و دوباره صفحه را بررسی کنید.

🎉 نتیجه نهایی

اگر تمام مراحل را به‌درستی انجام داده باشید، سایت شما باید از طریق دامنه شخصی در دسترس باشد.

آدرس سایت:

https://mozouni.ir

همچنین آدرس نسخه www نیز می‌تواند به سایت شما متصل باشد: 

https://www.mozouni.ir

💡 نکات مهم قبل از انتشار

  • نام فایل اصلی سایت را index.html قرار دهید.
  • مطمئن شوید فایل‌ها در مسیر صحیح Repository قرار دارند.
  • Name Serverهای Cloudflare را دقیقاً همان‌طور که Cloudflare نمایش می‌دهد وارد کنید.
  • برای رکوردهای DNS از مقادیر صحیح GitHub Pages استفاده کنید.
  • بعد از تغییر DNS کمی زمان برای انتشار تنظیمات در نظر بگیرید.
  • پس از فعال شدن SSL، استفاده از HTTPS را فعال کنید.
  • تنظیمات GitHub و Cloudflare ممکن است در آینده تغییر کند؛ بنابراین ممکن است نام بعضی گزینه‌ها با نسخه فعلی متفاوت باشد.
